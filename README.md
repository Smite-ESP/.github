## 🎮 About SMITE

SMITE is a third-person multiplayer online battle arena in which players control gods and mythological figures in team-based combat. The original game remains distinct from its sequel, SMITE 2; it is in maintenance mode, with no new content updates reported since February 2025.

| Detail | Information |
|---|---|

| Genre | MOBA, Action, Third-Person |
| Modes | Conquest, Arena, Joust, and other multiplayer modes |
| Platforms | Windows, PlayStation, Xbox |
